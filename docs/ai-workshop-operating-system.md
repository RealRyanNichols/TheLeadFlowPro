## The operator curriculum

### The five-part operator loop

1. Brief: define the job, context, limits, facts, and finished result.
2. Build: create one useful business asset from the real facts.
3. Check: verify truth, voice, risk, and missing pieces.
4. Use: place the asset into the actual offer, page, form, follow-up, or workflow.
5. Measure: watch what happened and choose the next controlled improvement.

### The 90-minute class

| Time | Teaching job | Attendee output |
| --- | --- | --- |
| 0 to 10 | Explain Chat, Work, and Codex in plain English | Tool choice makes sense |
| 10 to 25 | Compare a vague request with an operator brief | First operator brief |
| 25 to 45 | Build an offer, page, form, and follow-up path live | Visible end-to-end example |
| 45 to 65 | Coach attendees through their own first build | Draft business asset |
| 65 to 78 | Map one attendee business | Practical hot-seat map |
| 78 to 88 | Answer real business questions | Corrected next move |
| 88 to 90 | Explain DIY, return, or implementation paths | No-pressure choice |

### What is deliberately left for the next level

The workshop does not attempt to install ten tools, automate an entire company, build a full CRM, teach custom software engineering, or introduce Claude. Those topics require separate time, access, testing, and risk review. The reason is learning quality and business safety, not artificial scarcity.

## Tool policy

### Tools used in the founding workshop

- ChatGPT for conversation, analysis, and the operator brief.
- ChatGPT Work features when they help organize the business task.
- Codex for a controlled live build when code is part of the demonstrated asset.
- A browser and the attendee's real business facts.

### Tools used behind the event

- Next.js and Vercel for the funnel and preview.
- Supabase for events, policies, seat holds, registrations, and progress check-ins.

- Resend for transactional confirmation email.

### Tools saved for advanced workshops

- Claude, Claude Code, and Claude CoWork.
- Multi-agent workflows.
- Broad company automation.

## Learning controls

- One framework is repeated through the whole class.
- Every example starts with a real business job.
- Practice follows demonstration within the same segment.
- Ryan checks work while attendees are still in the room.
- Each attendee leaves with only one next move.
- The seven-day check-in asks what was built, what changed, where the person is stuck, and what comes next.
- Implementation follow-up is opt-in.

## Progress monitoring

The progress loop uses three checkpoints:

1. Before class: one bottleneck and one definition of a useful result.
2. Seven days: work completed, observed change, blocker, and next action.
3. Thirty days: retained use, repeatability, risk, and whether a larger system is justified.

Monitoring should identify drift early without taking control away from the customer. Ryan can correct the method. Pat can qualify implementation needs only when the attendee asks for help.

## Operating runbook

### Seven days before

- Confirm date, policies, clinic, private address treatment, instructor needs, and recording plan.
- Open sales only after the database readiness gate passes.
- Verify Stripe in test mode after Ryan approves the test.
- Review attendee bottlenecks and choose a live-build example that is useful but safe.

### Event day

- Verify room, display, internet, power, audio, camera cards, and backup screen recording.
- Check attendees against paid registrations.
- Repeat recording expectations at check-in.
- Keep the exact 90-minute clock.
- Deliver every Next Move card.
- Ask for honest reviews only after the promised value is delivered.

### One day after

- Mark attended and no-show statuses.
- Send operational follow-up and the seven-day progress link.
- Create Pat tasks only for attendees who request implementation help.
- Log review requests, testimonials, and permission status.

### Seven days after

- Review progress submissions.
- Correct obvious left-field drift with one clear next move.
- Close the $97 System Map credit window.
- Record cash collected and next-stage outcomes.
