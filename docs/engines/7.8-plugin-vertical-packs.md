# Engine 7.8: Plugin vertical packs

Status: built on a branch. Three packs are defined as drafts; none is
marketed, none is priced, and the audit says exactly what is missing from
each. Decisions 40 and 41 in `docs/decisions-needed.md`.

## What it is

Industry editions of the plugin on the same engine (`lib/hq`): a pack is
a named set of workflows and prompts for one trade, each workflow built
from engine tools that exist today or marked as missing. The rule from
the Phase 3 audit is in code: a pack is `real` only when every workflow
in it exists, its product page renders only then, and its price stays the
TBD line until Ryan sets a number.

## What the engine does with a pack today

`packForWorkspace(ws)` matches the workspace's industry label. The only
behavior change on this branch: when a lead has no service and the
workspace lists several, the drafts say "your estimate request", "your
appointment request", or "your showing request" instead of "your
request". A named service always wins. Every text still ends with the
opt-out line.

## Runbook: making a pack real

1. Build the missing workflow in the engine (a tool in `lib/hq/mcp.ts`,
   a cron step, or a field), with its tests.
2. Set `exists: true` on that workflow in `lib/hq/verticals.ts` and
   delete its `missing` note.
3. When every workflow in the pack exists, `npm run plugin:packs` reports
   REAL and the page renders. Add the pack page to
   `lib/publicPageCatalog.ts` so the sitemap and OG card follow.
4. Ryan sets the price in `lib/site/offers.ts` (status `live`). Until
   then the page shows the TBD line.
5. Plugin docs and the /plugin page mention the pack only after 3 and 4.

## Limits

- Packs change vocabulary and add prompts. They do not yet change the
  follow-up day ladder or the brief's ranking per trade.
- Industry matching is by the exact HQ label; a workspace with a custom
  industry gets the default engine.
- Nothing here changes billing. A pack price, when set, needs its own
  Stripe product and a purchase kind, which is decision 41.

## Rollback

Revert the merge. The only live behavior change is the fallback noun in
three drafts.
